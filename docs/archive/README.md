implementation sequence. Their restrictions, package choices, and future-work
gates do not govern the replacement.

- [Research plan](RESEARCH_PLAN.md): original thesis and target architecture.
- [Initial implementation plan](INITIAL_IMPLEMENTATION_PLAN.md): old phase history.

The active [product plan](../../PLAN.md), [implementation plan](../INITIAL_PLAN.md),
and [contributor guide](../../CONTRIBUTING.md) supersede them. Old source remains
only until the initial-base gate passes and R5 removes it. Historical documents
may retain old statements in their original context; the archive notice takes
precedence for current work.
